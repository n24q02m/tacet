## 2025-01-20 - Global Focus Visible Outline
**Learning:** Relying solely on brightness filters or text color changes for focus states provides insufficient visual feedback for keyboard users, making navigation difficult to track.
**Action:** Implement a clear, universal `:focus-visible` outline using `outline: 2px solid var(--accent); outline-offset: 2px;` to ensure consistent and obvious keyboard accessibility across all interactive elements.
