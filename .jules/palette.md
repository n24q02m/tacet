## 2024-05-20 - Add skip-to-content link
**Learning:** The main content wrapper was missing an ID and there was no mechanism for keyboard users to bypass the site header and navigation. This is a common accessibility omission in simple documentation/academic sites.
**Action:** Always verify keyboard navigation can efficiently reach the main content, especially when there's a site-wide navigation header, by adding a visually hidden skip link that becomes visible on focus.
